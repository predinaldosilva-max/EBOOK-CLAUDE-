# v2.0.6 — dispensar aviso financeiro legado

A home e a seção de consulta oferecem Já conferi — não mostrar novamente. A escolha fica no armazenamento local, separada por licença, e oculta somente o aviso da home após recarregar. Mais ferramentas preserva consulta, exportação e cópia explícita dos dados antigos. Baixar backup continua sendo uma ação separada; não oculta silenciosamente o aviso nem afirma que o arquivo foi salvo pelo sistema.

Nenhum registro legado, cofre, credencial ou banco é apagado/importado pela dispensa. Falha de armazenamento mostra erro e não oculta o aviso somente na memória. Outra licença não herda a dispensa. Limpar dados do navegador remove a preferência, assim como os demais dados locais.

Teste novo verificou dispensa, recarga em outra instância de DOM com armazenamento preservado, exportação semanticamente igual, preservação do original e isolamento da preferência entre licenças. Suíte completa: 52 casos Node, 41 básicos, 26 verificações de qualidade com 5.000 cenários matemáticos, 11 de dispositivo, 300 assertions financeiras. Quatro testes de build também aprovados. Interface simulada; sem nova conferência física. PT/ES/EN e cache/rótulos v2.0.6. Backend, D1 e autenticação preservados. Rollback: d685304453d87e040f2a04be9392aaba0cf6ba06.

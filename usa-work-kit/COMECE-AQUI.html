USA WORK KIT

Smart Tools for Workers · v1.0.3

Português

  1. Extraia a pasta inteira do ZIP.
  2. No celular, abra a versão online no Safari do iPhone ou Chrome do Android. Computadores e tablets são bloqueados.
  3. Digite a senha recebida do vendedor. Escolha PT-BR ou Español e uma ferramenta.
  4. Preencha os dados. Os resultados são estimativas baseadas nos valores informados.
  5. Salve registros e use Relatórios e backup → Exportar backup JSON regularmente.

No celular, utilize uma publicação HTTPS compatível. Abrir HTML no aplicativo Arquivos pode mostrar apenas uma prévia. A versão de testes está neste endereço; a hospedagem para distribuição comercial requer confirmação. Consulte docs/HOSPEDAGEM.md.

Español

  1. Extrae toda la carpeta del ZIP.
  2. En el celular, abre la versión online en Safari del iPhone o Chrome de Android. Computadoras y tabletas están bloqueadas.
  3. Introduce la contraseña del vendedor. Selecciona Español y una herramienta. Los cálculos son estimaciones.
  4. Guarda tus registros y exporta respaldos JSON regularmente.

En el móvil se requiere una publicación HTTPS compatible; el visor de archivos puede no ejecutar la aplicación. Consulta docs/MANUAL-ES.md.

Sin sincronización: borrar datos del navegador puede borrar tus registros. No introduzcas contraseñas ni datos bancarios.

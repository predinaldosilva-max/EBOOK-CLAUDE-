# Comece aqui / Empieza aquí

## Português

1. No celular, abra a URL HTTPS no Safari do iPhone ou Chrome do Android. Computadores e tablets são bloqueados. Não é necessário cadastro.
2. Escolha o idioma no canto superior direito.
3. Abra Calculadora de entregas: pagamento 20; gorjeta adicional 5; milhas 10; custo/milha 0,50; tempo 25; espera 5; meta/hora 30.
4. Confira: resultado estimado US$ 20,00; US$ 40,00 por hora. Não registre esse exemplo como receita real.
5. Use Relatórios e backup → Exportar backup JSON para proteger seus dados.

Celular: consulte HOSPEDAGEM.md. O ZIP não equivale a um aplicativo instalado; abrir HTML no app Arquivos do iPhone não é um caminho garantido. A publicação HTTPS para uso comercial não foi realizada e precisa respeitar os termos da hospedagem.

## Español

1. En el celular, abre la URL HTTPS en Safari del iPhone o Chrome de Android. Computadoras y tabletas están bloqueadas. No necesitas registro.
2. Elige Español arriba a la derecha.
3. En entregas introduce pago 20; propina adicional 5; millas 10; costo/milla 0,50; tiempo 25; espera 5; meta/hora 30.
4. Comprueba: resultado estimado $20,00; $40,00 por hora. No registres este ejemplo como ingreso real.
5. En Informes y respaldo, exporta JSON para proteger tus datos.

Móvil: consulta HOSPEDAGEM.md. El ZIP no es una aplicación instalada; abrir HTML en Archivos del iPhone no garantiza ejecución. No se ha publicado una versión HTTPS comercial y debe respetar los términos del proveedor.


## Acesso com senha — versão 1.0.3
Abra no celular e digite a senha individual fornecida pelo vendedor após a confirmação da compra. O navegador lembra o acesso quando o armazenamento está disponível. Para fechar o acesso, toque em Bloquear acesso. Os registros financeiros não são apagados. Se limpar os dados do navegador, será necessário informar a senha novamente. Guarde sua senha. O backup JSON de registros não inclui a senha. Não existe vinculação a um único aparelho nesta versão. O vendedor não solicita senha da Kiwify nem de aplicativos de trabalho.
